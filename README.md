# The Hall of Weird

**https://dnl-strnl.github.io/hall-of-weird/**

Enshrining the oddities of baseball. Every inductee was discovered by a
*detector* — an extreme-value query run across all of MLB history (1871–present) —
or pulled from the record book, where the weirdness runs all the way back to
baseball's prehistory. Nobody is here for being great — they are here for being
*unbelievable*.

Each inductee is one YAML file in [`_data/inductees/`](_data/inductees/);
GitHub Pages compiles them into the exhibit wall at build time. The hall opened
empty on 10-10-2026 and grows as the impossible is discovered.

> [!NOTE]

[CONTRIBUTING.md](CONTRIBUTING.md).

## Local preview

```bash
bundle install
bundle exec jekyll serve --livereload
```
Then, open <http://localhost:4000/> in your web browser.

Drop a YAML into `_data/inductees/` and the exhibit appears on refresh.
